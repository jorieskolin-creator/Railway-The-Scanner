Score Drift Analysis

Why did the scanner produce different results this time? Is it noise or genuine change?

The system autonomously monitors score stability. If a score drift of ≥25 points is detected within 7 days, the agent automatically initiates a self-correction sequence to validate the variance.

Autonomous Decision & Self-Correction:Upon detecting a ≥25pt delta threshold breach (vs. previous scan, within 7 days), the system halts finalization and triggers a 'Diagnostic Mode' rescan. This autonomous loop isolates specific variables to determine if the drift is an error (which it self-corrects) or a legitimate evolution.

Meta-Cognitive Reflection

Reflective Agent

This agent does not analyze the company; it analyzes the system's own output. It observes 'Drift' (variance) and initiates a diagnostic subroutine to determine if the cause is hallucination (noise) or reality (genuine change), self-correcting the final score.

Input Assembly

The report doesn't work from raw data — it receives a carefully curated input payload assembled from already-validated upstream sources:

Evidence Pool:Up to 20 verified forensic evidence links + up to 5 validated foresight sources
Key Findings:Up to 12 reality checklist items (only confirmed findings with URLs, legal pages pre-filtered)
Financial Data:Financial index, sub-scores, and up to 5 financial findings
Key People:Up to 6 people with enrichment data — headlines, career moves, expertise topics
Washing Flags:Flagged if a gap between stated ambitions and reality was detected
Historical Delta:If prior scan data exists, includes trajectory changes over time

System Philosophy

The system follows a "validate inputs, constrain outputs, verify outputs" philosophy. Foresight sources are verified before they're used. Legal pages are pre-filtered. Prompts enforce strict evidence discipline ("no evidence = no claim"). Quality control is both front-loaded into the data pipeline AND applied as post-generation verification on narrative outputs.

The General Summary is assembled from already-verified structured data, then passes through payload-based fact-checking (fact_check_general_summary()) which verifies every claim traces back to the validated input payload — if unsupported claims are detected, the summary is automatically regenerated. The Detailed Forensic Report relies on the fact that its input data is already validated upstream — purged evidence links, validated foresight sources, and pre-filtered legal pages.

Accuracy Safeguards

✓ No internal scores mentioned by name or number in any output.

✓ Legal/ToS pages are pre-filtered from evidence before prompts are built.

✓ Foresight data enters the report only if it passed URL verification AND credibility assessment.

Supervisor / Judge

Evaluator Agent

Acting as an impartial arbiter, this agent receives inputs from the Intent and Reality agents. It blindly re-evaluates the raw evidence to detect bias in the sub-agents. If it finds a discrepancy >10pts, it has the authority to override the previous agents' conclusions. Then assembles curated, validated input payloads for forensic report generation.

Independent Verification

Are the claims in the AI-generated summary actually TRUE?

An independent AI model with live web search reads the generated summary and pitch, then independently verifies every factual claim. Foresight data goes through a dedicated 3-step validation pipeline before it can enter any downstream section.

3-Step Foresight Validation Pipeline

01
URL Verification
Parallel HTTP probes on every source URL the AI cited. Each is marked as verified or unverified.
02
SIFT Reality Check
Evaluates source type, domain credibility, self-reporting detection, and OSINT validation quality for each force.
03
Link Extraction
Only forces that pass validation (verified URL + credible source + ≤2 flags) are extracted for downstream use.

Accuracy Safeguards

✓ Company self-reporting is automatically detected and flagged when the source URL matches the company's own domain.

✓ Single-pass guarantee: the fact-check runs EXACTLY once — no recursive loops.

✓ Legal and Terms of Service pages are pre-filtered from evidence before any prompt is built, preventing misinterpretation of conditional language as factual events.

Independent Fact-Checking Agent

Live Web Access / Quality Gate

Acts as a quality gate with a 3-step validation pipeline: URL verification, SIFT reality checks with credibility whitelists, and link extraction. Can autonomously purge evidence, downgrade confidence, and correct outputs. Single-pass execution ensures no recursive loops.
